## 💰 The Problem

When a property is sold at foreclosure auction for **more than the debt owed**, the excess — the **surplus funds** — legally belongs to the former homeowner.

The catch: nobody is obliged to knock on the door and tell them. Claim windows expire by state. Paperwork is unfamiliar. And the people most entitled to the money are usually the least equipped, at the worst possible moment, to go and get it.

**Surplus Recoveries** exists to close that gap — and this repository holds both the public-facing site and the internal training material behind the business.

## 🚀 Deployment

The site auto-deploys to **Vercel** on every push to the default branch.

```bash
git add .
git commit -m "your message"
git push
```

**Local preview** — no build step required:

```bash
python -m http.server 8000     # then open http://localhost:8000
```

`vercel.json` enables clean URLs, so `/blog/what-are-surplus-funds` resolves without the `.html` extension.
